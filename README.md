# RBO Accounting Services FZE Website

Official website for **RBO Accounting Services FZE** — FTA-approved corporate tax, VAT registration & return filing, audit, and accounting services in the UAE.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React & React Icons
- **Animations**: Framer Motion
- **Language**: TypeScript

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run local development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production
```bash
npm run build
npm run start
```
